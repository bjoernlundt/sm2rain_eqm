This repository contains the code for the paper draft "Better representation of daily precipitation extremes for SM2RAIN-products in West Africa with Empirical Quantile Mapping"

Author: Björn Lundt

Affiliation:    1. Chair for Regional Climate and Hydrology, Department of Geography, University of Augsburg, Germany
                2. Deutsches Zentrum für Luft- und Raumfahrt e.V. (DLR), Oberpfaffenhofen, Germany

The repo contains the following .ipynb files for data analysis and implementation of the methods described in the paper:
1. preprocessing.ipynb: Preprocessing of the SM2RAIN datasets
2. qm_final.ipynb: Implementation of the quantile mapping method in different spatial and temporal aggregation levels

3. requirements.txt: List of required packages for the implementation of the code
4. README.txt: This file
